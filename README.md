# FIABD County and State Volume Summary Tool
County level analysis completed, state still under work.

- Run the python script and enter the state the analysis is to be made on.
- If the FIA files for state entered are not present in the directory, rFIA automatically downloads them.
- All analysis of net and gross volume will be listed under Results/{State}.
- Several files are outputted, each from data from different years. The years are listed on the file name.
